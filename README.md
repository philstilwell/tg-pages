# Tokyo Girl

Published website files for the Tokyo Girl Japanese study companion.

[Open the main Tokyo Girl study site](https://philstilwell.github.io/tg-pages/).

Student progress, notes, expressions, and recordings stay in each browser. Use the website’s backup controls to move text progress between devices. No student saves are stored in this repository.

These files are generated from the maintained private `philstilwell/tg` project. Changes committed and pushed to its main branch are checked and published here automatically. Do not edit this generated repository directly.
